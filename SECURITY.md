# Security Policy

## Current Version

Currently, the latest version of Telegram Bot is **2.0.0**. An information about the newest update can be found in the
Releases section.

## Supported Versions

A release stays partially supported until three more minor versions have come out after it.

|      Version      |   Support status   |
|:-----------------:|:------------------:|
|      _2.0.x_      | :white_check_mark: |
| _1.41.x - 1.39.x_ | :heavy_check_mark: |
| _1.38.x - 0.1.x_  |        :x:         |

:white_check_mark: - _Fully supported_ - You can expect to get an update on every reported vulnerability/problem.

:heavy_check_mark: - _Partially supported_ - You can expect to get an update on some reported vulnerabilities/problems.

:x: - _Not supported_ - You cannot expect to get any update on a reported vulnerability/problem. Please, update your
script.

## Reporting a Vulnerability

To report a vulnerability, please create an issue. Most reported vulnerability should be accepted. You can expect to get
an update on a reported vulnerability at least once a week.
